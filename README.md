# Darb's Journey

Welcome to **Darb's Journey**! This is a fun and interactive web project that challenges users to enter a password. Depending on the input, users are either rewarded with a celebratory video or shown an error message with a humorous twist.

## About the Project
This project is a simple yet engaging web application where users are prompted to enter a password. If the password is correct, a congratulatory video plays, and the user is redirected to another page. If the password is incorrect, an error video is displayed. The project is designed to be lighthearted and entertaining.

## Features
- **Password Check**: Users can input a password and check if it's correct.
- **Interactive Feedback**:
  - **Success**: A celebratory video plays, and a button appears to redirect the user.
  - **Error**: A humorous error video plays if the password is incorrect.
- **Confetti Animation**: Adds a festive touch when the password is correct.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.

## Technologies Used
- **HTML5**: Structure of the website.
- **CSS3**: Styling and animations, including the confetti effect.
- **JavaScript**: Handles password validation, video playback, and redirection logic.
- **MP4 Videos**: Used for success and error feedback.
